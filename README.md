# MQTT 시계열 추론 — 교육장 센서 데이터로 "지금 무슨 일이, 곧 어떻게"

교육장(강의실·회의실·라운지)의 CO₂·온도·습도 센서 데이터를 **MQTT로 수집**하고, **60분 예측·이상 탐지·사용 여부 추정**을 학습한 뒤, **Jetson Orin Nano에서 매분 도는 상시 추론 서비스**로 만든 실습 결과다. (team2, 기본 트랙)

> 🔰 **처음이라면 여기부터 → [처음 보는 사람을 위한 안내서](docs/10_초보자가이드.md)**  
> 비유와 그림으로 전체 흐름, 꼭 필요한 개념, 과제별 결과, 용어 사전, 자주 하는 질문을 정리했다.

## 핵심 결과 (합성 데이터 시험 기간)

| 과제 | 결과 |
|---|---|
| 60분 CO₂ 예측 | 현재값 유지 45.3 → **GRU 18.0ppm (−60%)**, 일정 정보로 회의실 −40% |
| 이상 탐지 | 고장 17건 중 **14건(82%)**, 헛경보 **하루 0.29회** |
| 사용 여부 추정 | F1 **0.842**, 빈 방 → 사용중 오판 **0.2%** |
| 환기 선제 경보 | 재현율 **0.860** (예측 모델로 판단하면 0.897) |
| TensorRT 변환 | CO₂ 차이 **0.71ppm** (FP16 + 출력부 FP32), 분류 변화 0% |
| 상시 서비스 | 매분 0.4초, 학습-서비스 입력 차이 **0**, 수집기 정지 시 경보·복귀, 유실 0 |

## 시스템 구성

```
센서(LoRaWAN) → ChirpStack → MQTT ─▶ 수집기(Docker) ─▶ InfluxDB
                                                         │
          합성 재생기 ─▶ MQTT(:1885) ─▶ 수집기-sim ────────┤
                                                         ▼
                       추론 서비스(systemd, 매분) ─▶ MQTT 발행(retain) + 조회 API(:8091)
                       └ service_kit: 공통 전처리 → GRU 예측 / 오토인코더 + 규칙 / 상태 분류
```

## 코드 (`code/`)

| 폴더 | 내용 |
|---|---|
| `ingest/` | 수집 스택: `docker-compose.yml`, 설정 기반 MQTT 수집기(`collector/`), 커버율 보고 |
| `common/preprocess.py` | **학습·서비스 공용 정제 규칙** (범위 밖 제거, 5분 격자, 결측 처리) |
| `task2/` ~ `task7/` | 과제별 진단·학습·평가·변환·측정 스크립트 |
| `service/` | 상시 추론 서비스(`service.py`), 브로커·재생기·수집기-sim, systemd 유닛, 장애 시험, 가동 요약 |
| `service_kit/` | 추론 키트(`kit.py`)와 학습-서비스 전처리 일치 시험 |
| `tools/` | 운영진 InfluxDB 과거 데이터 이관(읽기 전용 토큰 → Parquet → 로컬 InfluxDB), MQTT·DB 조사 |

### 실행 환경과 주의

- Jetson Orin Nano Super (L4T R39.2.1, 25W), Python 3.12, PyTorch 2.11(CUDA 13), TensorRT 10.16, ONNX Runtime 1.31, InfluxDB 2.7, Mosquitto 2.
- 코드는 보드의 팀 공용 경로(`/srv/team/...`)를 기준으로 작성되어 있다. 다른 환경에서는 경로를 바꿔야 한다.
- **올리지 않은 것**: 접속 정보(`.env`: 브로커·DB 주소, 토큰, 비밀번호), 데이터(합성·실데이터·Parquet), 학습된 모델·TensorRT 엔진. 각 스크립트를 실행하면 다시 만들어진다.
- 문서의 보드 주소는 `<JETSON_HOST>`로 가렸다.
- 합성 데이터는 제공 키트가 없어 과제 안내문 규칙대로 **팀에서 직접 만든 생성기**로 만들었다(seed 42, 6주, 시험 주간 고장 17건).
