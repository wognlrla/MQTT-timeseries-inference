# 과제 3. 60분 예측 (초안)

**측정 조건**: 합성 데이터(seed 42, 팀 자체 생성기), 학습 08-31~09-27 / 검증 09-28~10-04 / 시험 10-05~10-11.
평가 시점은 과제 2와 동일(`task2/out/eval_points.csv`, 시험 7,690개). 주 성적은 고장 앞뒤 60분을 뺀 시점이다.
보드: Jetson Orin Nano Super (전력 모드 미설정 = 기본), PyTorch 2.11 + CUDA 13, 모델당 학습 1~1.5분.
모든 학습 모델은 시드 3개(0, 1, 2)로 학습했고, 표는 평균 ± 표준편차다.
재현: `train.py --name gru_sched --schedule 1` / `--name gru_nosched --schedule 0` / `--name gru_sched_abs --schedule 1 --target abs` → `evaluate.py`

## 1. 입력·출력 설계

| 항목 | 선택 | 이유 |
|---|---|---|
| 과거 길이 | **2시간 (24칸)** | 수업 1교시(50분)와 쉬는 시간이 두 번 들어가는 길이. 하루를 넣으면 '어제 같은 시각'처럼 하루 변동에 휘둘린다(과제 2) |
| 센서 입력 | CO₂·온도·습도 (학습 기간 정규화) + 항목별 결측 표시 | 긴 결측이 있어도 평가 시점을 빠뜨리지 않고 예측하기 위해 결측을 0으로 채우고 표시를 함께 준다 |
| 시간 정보 | 시각·요일 (sin/cos), 주말 여부 | 수업·냉방 시간이 시각에 묶여 있다 |
| 공간 | 원-핫 4개 | 공간마다 부피가 달라 같은 인원에도 오르는 폭이 다르다 |
| **일정** | 과거 2시간 + **앞으로 60분**의 일정 진행 여부, 예상 인원/정원 | 일정은 미래 값도 미리 알 수 있다. 센서는 6~8분 늦게 반응한다(과제 2) |
| 출력 | 5~60분 12칸 × (CO₂, 온도)를 **한 번에** 출력 | 한 칸씩 반복 예측하면 앞 칸의 오차가 뒤로 쌓인다 |
| 출력 형태 | **지금 값에서의 변화량** (기본) / 절댓값 (비교용) | 4절에서 비교 |
| 모델 | GRU 2층(은닉 64) → 일정·시간·공간과 합쳐 MLP | 기본 트랙 요건(LSTM·GRU·TCN 중 1종) |
| 학습 | 학습 기간, 입력+출력 구간에 고장이 없는 시점만 (32,004개). 손실 L1. 검증 손실로 조기 종료 | 시험 기간은 학습·모델 선택에 쓰지 않음 |

## 2. 모델 비교표 (시험 기간, 고장 제외, MAE)

| 모델 | CO₂ 5분 | 15분 | 30분 | **60분** | 온도 5분 | 15분 | 30분 | **60분** |
|---|---|---|---|---|---|---|---|---|
| 현재값 유지 | 10.2 | 19.7 | 30.2 | 45.3 | 0.09 | 0.23 | 0.45 | 0.86 |
| 최근 1시간 평균 | 27.1 | 33.0 | 40.8 | 54.0 | 0.46 | 0.60 | 0.81 | 1.21 |
| 어제 같은 시각 | 91.8 | 92.1 | 93.0 | 94.8 | 1.31 | 1.31 | 1.31 | 1.31 |
| GRU (일정 제외) | 7.2 ±0.3 | 12.0 ±0.3 | 17.1 ±0.4 | 24.3 ±0.4 | 0.07 | 0.11 | 0.17 | 0.29 ±0.03 |
| **GRU (일정 포함)** | **6.5** ±0.2 | **9.2** ±0.1 | **12.6** ±0.2 | **18.0** ±0.4 | **0.06** | **0.11** | **0.17** | **0.29** ±0.01 |
| GRU (일정 포함, 절댓값 예측) | 10.4 ±1.2 | 12.0 ±0.6 | 14.2 ±0.3 | 19.7 ±2.0 | 0.21 | 0.21 | 0.24 | 0.38 |

CO₂는 ppm, 온도는 ℃. 고장 구간까지 포함하면 60분 CO₂는 현재값 유지 56.8 → GRU(일정 포함) 33.8ppm.

### 확인 기준

| 기준 | 결과 | 판정 |
|---|---|---|
| 60분 CO₂ 오차가 현재값 유지보다 30% 이상 작다 | 45.3 → **18.0ppm (−60%)**. 일정 제외 모델도 24.3ppm (−46%) | ✅ |
| 온도 60분 예측이 현재값 유지보다 좋다 | 0.86 → **0.29℃ (−66%)** | ✅ |
| 시험 기간을 학습·모델 선택에 쓰지 않았다 | 조기 종료는 검증 손실, 정규화는 학습 기간 값 | ✅ |

## 3. 공간별 분석 (60분, 시험, 고장 제외)

| 공간 | 현재값 유지 | GRU 일정 제외 | GRU 일정 포함 | 일정 효과 |
|---|---|---|---|---|
| 강의실 A | 46.2 | 22.7 | 17.7 | −5.1ppm |
| 강의실 B | 66.1 | 25.6 | 20.5 | −5.1ppm |
| 라운지 | 43.9 | 22.7 | 18.2 | −4.5ppm |
| **회의실** | 27.4 | **26.3** | **15.8** | **−10.5ppm (−40%)** |

- **회의실은 일정 정보 없이는 거의 예측하지 못한다.** 일정 제외 GRU가 현재값 유지(27.4)와 거의 같은 26.3ppm이다. 회의는 날마다 시각이 다르고, 회의 직전의 센서값에는 곧 회의가 시작된다는 흔적이 전혀 없다. **과거 센서값에 없는 정보, 즉 '언제 누가 들어오는가'는 예약 시스템에만 있다.** 그래서 일정을 넣었을 때 개선 폭이 가장 크다(−40%).
- **강의실은 일정 없이도 잘 맞는다.** 시간표가 매일 같아서 모델이 '시각 + 요일'만으로 수업 패턴을 배운다. 일정 정보는 휴강 같은 예외를 알려 주는 정도로만 기여한다.
- **온도는 일정 효과가 없다(0.29 → 0.29℃).** 온도는 냉방 시간과 바깥 날씨가 대부분을 정하고, 이는 시각 정보로 충분하다. 사람 발열의 영향은 냉방이 상쇄한다.

## 4. 일정 정보의 가치

> **일정 정보를 넣으면 60분 CO₂ 예측 오차가 24.3 → 18.0ppm으로 6.4ppm(26%) 줄어든다. 회의실에서는 10.5ppm(40%) 줄어든다.**

상황별로 나누면 효과가 어디서 나오는지 보인다(회의실, 60분 CO₂, 시험).

| 상황 (평가 시점 수) | 현재값 유지 | GRU 일정 제외 | GRU 일정 포함 |
|---|---|---|---|
| 일정 없음 (1,509) | 6.0 | 8.9 | 5.6 |
| **시작 1시간 전** (99) | 177.6 | 176.1 | **126.8** |
| **일정 중** (72) | 179.3 | 153.7 | **67.6** |
| 끝난 뒤 1시간 (78) | 110.0 | 54.1 | 22.8 |

## 5. 생각해 볼 점에 대한 답

**변화량 예측 vs 절댓값 예측**
- 변화량으로 예측하면 '지금 값'이 그대로 기준이 되어, **짧은 예측에서 훨씬 정확하다**(5분 CO₂ 6.5 vs 10.4ppm, 온도 0.06 vs 0.21℃). 절댓값 모델은 지금 수준을 매번 새로 맞혀야 해서 작은 오차가 늘 남는다.
- 절댓값 모델은 회의실 '끝난 뒤 1시간'(12.7 vs 22.8ppm)처럼 **외기 수준으로 돌아가는 구간**에서는 조금 낫다. 돌아갈 목표값(약 420ppm)을 직접 배우기 때문이다. 하지만 시드마다 결과가 크게 흔들려서(±2.0ppm) **변화량 방식을 채택**한다.

**오차가 가장 큰 순간**
- 모든 공간에서 **일정 시작 1시간 전 → 시작 직후**의 오차가 가장 크다(회의실 127ppm, 강의실 65ppm, 라운지 42ppm). 그 외 시간의 오차는 4~10ppm이다.
- 일정을 알아도 **실제로 몇 명이 언제 올지**(노쇼 15%, 지각, 결석)는 모른다. 예시 그래프(`out/fig_example_2026-10-07.png`)의 회의실 오전 회의에서, 모델은 예약 인원을 믿고 1,000ppm을 예측했지만 실제로는 790ppm이었다.
- 창문 개방이나 쉬는 시간의 급락(강의실 A 15:00, 540ppm까지 떨어짐)은 일정 자료에 없어서 맞히기 어렵다. 이 순간을 맞히려면 **출입 인원 센서나 창문 개폐 센서**가 필요하다.

**예측과 고장 탐지의 연결 (과제 4로 넘김)**
- 예시 그래프의 회의실 15:30~17:30 예약 구간은 **센서 값 고정 고장**이 있었던 구간이다. 일정을 아는 모델은 회의 때문에 CO₂가 오를 것으로 예측했는데, 센서는 평평한 값을 보냈다. **"예약은 있는데 CO₂가 안 오른다"는 예측 오차가 고장 신호가 된다.** 과제 4 심화(예측 오차 기반 탐지)의 근거다.
